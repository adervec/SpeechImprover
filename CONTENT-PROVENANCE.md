# Content provenance & licensing

Everything the app ships as *reading material* is either written for this project
or public domain **worldwide**. This file records what, where from, and how it is
checked. Run the check locally with `npm run audit:content` (it also runs in CI).

## 1. Original content (written for SpeechImprover — MIT with the repo)

| Where | What |
|---|---|
| `src/lib/drillCatalog.js` | 65 targeted drills / 263 text variants, 8-item warm-up pool |
| `src/lib/exercises.js` | 3 featured passages ("The Turning Tide", "How an Engine Works", "Civic Notice"), free-speaking & interview prompts, over-articulation / expressive read lines |

## 2. Public-domain library (`src/lib/readingPassages.generated.js`)

Generated by `scripts/scrape-passages.mjs` from Project Gutenberg plain-text
files. Only the underlying prose/verse is kept — every Gutenberg header, footer,
licence block and trademark string is stripped, and each passage is attributed
to the original title + author (+ translator, when a translation).

**Rights policy** (enforced in the script; entries failing it are skipped and
listed in the build log):

* first published ≤ *current year − 96* → US public domain (95-year rule), **and**
* every author *and translator* died ≤ *current year − 71* → life+70 public
  domain (EU/UK/most of the world).

So the corpus is PD in the US **and** in life+70 jurisdictions, not just one of
them. Deliberately excluded for that reason (US-PD but not yet life+70): Agatha
Christie, Robert Frost, Bertrand Russell, T. S. Eliot, Carl Sandburg, W. E. B.
Du Bois, Mary Roberts Rinehart, plus translations by Lionel Giles (Sun Tzu),
W. D. Ross (Aristotle), C. K. Ogden (Wittgenstein), and the modern (© 2001–2002)
Kafka and Hesse translations. *Peter Pan* is excluded because of the UK's
perpetual GOSH royalty right (CDPA 1988 s.301). *The Prince* (Marriott) and the
Taylor/Edwardes *Grimm* were dropped because the translator/editor's dates could
not be verified; the Margaret Hunt *Household Tales* (d. 1912) is used instead.

**Provenance check**: every fetched file's `Title:` / `Language:` header must
match the catalog entry (a wrong Gutenberg id otherwise silently attributes the
wrong book — the August 2026 audit found five such cases in the old catalog,
including a Spanish-language *Don Quijote* and a Buchan novel filed under Conan
Doyle; all fixed).

**Curated passages** (hand-typed, in the same script): Lincoln (Gettysburg,
Second Inaugural), Patrick Henry, Sojourner Truth, six Shakespeare set pieces,
Frederick Douglass (1852), Susan B. Anthony (1873), Chief Joseph (1877),
Pericles' funeral oration (Thucydides, Crawley tr. 1874), the Declaration of
Independence preamble, and short verse by Kipling ("If—", 1910; d. 1936),
Henley, Shelley, Wordsworth and Blake.

`npm run audit:content` re-verifies the committed corpus: every passage maps to
a catalog entry that passes the policy, titles have not drifted, and no
Gutenberg boilerplate or unexpected characters remain.

## 3. Traditional / folk material

Tongue-twisters ("She sells seashells", "Peter Piper", "Red leather, yellow
leather", "Round the rugged rocks…", "A proper copper coffee pot", "Unique New
York", "Good blood, bad blood", "toy boat", "the sixth sick sheikh's sixth
sheep") are 19th-century or older folk rhymes with no identifiable author —
public domain. The butter twister is a reworded line after Carolyn Wells'
"Betty Botter" (1899; d. 1942 — PD worldwide).

## 4. What is *not* included

No song lyrics, no excerpts from in-copyright books or speeches (e.g. Churchill,
Kennedy, King), no third-party guide text. If you add reading material, add it
to the scraper catalog with `pub`/`died` (and `translator`) so the policy can
vet it, or to §1 if you wrote it yourself.
