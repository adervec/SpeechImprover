# Contributing to SpeechImprover

Thanks for your interest! SpeechImprover is a small, free, non-commercial project, but
contributions (bug reports, fixes, new exercises, accessibility improvements) are very welcome.

By contributing, you agree that your contributions are licensed under the project's
[MIT License](LICENSE).

## Project layout

The app is a client-side React + Vite SPA living in [`speechimprover/`](speechimprover/).

```
speechimprover/
  src/            # app source (views, components, hooks, lib)
  scripts/        # tooling, incl. the reading-passage scraper
  public/         # static assets (favicon, baseline-guide.html)
design.md         # architecture & analysis design
```

## Getting set up

```bash
cd speechimprover
npm install
npm run dev        # http://localhost:53134
```

## Before you open a pull request

Please make sure both of these pass — CI runs them on every PR:

```bash
npm run lint
npm run build
```

- Target the **`dev`** branch with your PR (it's the integration branch; `main` deploys to GitHub Pages).
- Keep changes focused; describe **what** and **why** in the PR description.
- Match the existing code style (enforced by ESLint).

## A few project-specific notes

- **Don't hand-edit `src/lib/readingPassages.generated.js`** — it's auto-generated by
  `scripts/scrape-passages.mjs`. Change the script and regenerate instead.
- **Reading passages must be public domain** (the project sources them from
  [Project Gutenberg](https://www.gutenberg.org/)) and **English only** for now.
- **Keep medical/clinical claims out.** This is an experimental, educational tool, not a medical
  device (see [DISCLAIMER.md](DISCLAIMER.md)). Please don't add language implying diagnosis,
  treatment, or clinical validation.
- **Stay local-first / privacy-preserving.** Don't introduce analytics, trackers, or calls that
  send user audio or data to a server (see [PRIVACY.md](PRIVACY.md)).

## Reporting bugs & ideas

Open a [GitHub issue](https://github.com/adervec/SpeechImprover/issues) with steps to reproduce,
your browser/OS, and what you expected. For security issues, see [SECURITY.md](SECURITY.md).
